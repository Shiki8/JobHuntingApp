# 求人票データの生成は外部 LLM に委譲しバックエンドを持たない

求人票データ (JobImport) を生成する際、アプリが求人サイトの URL を直接取得・解析する方式は採用しない。代わりにユーザーが外部 LLM（Claude.ai・ChatGPT 等）を使って求人票を構造化 JSON に変換し、その結果をアプリに貼り付けるフローとする。

URL 直接取得方式では求人を登録するたびに LLM API の呼び出しコストが発生する。外部 LLM 委譲方式ならアプリ側に API コストが生じず、バックエンドも不要なためインフラ維持コストもかからない。将来バックエンドを追加する場合は JobImport の生成フロー全体を見直す必要がある。

## Considered Options

- **URL 直接取得 + サーバーサイドプロキシ**: CORS を回避できるが、バックエンドの構築・運用コストと API 呼び出し費用が都度発生する
- **ブラウザから URL を直接 fetch**: CORS により求人サイトの大半でブロックされる
- **外部 LLM 委譲（採用）**: バックエンド不要・API コストゼロ。変換精度はプロンプトテンプレートの品質に依存するが、ユーザーがフォームで確認・修正できるため許容範囲とした
