# ADR 0001: 合致度スコアの分母は全評価軸とする

## Status
Accepted

## Context
求人に対して評価軸の一部しか入力されていない場合、合致度スコア（weightedTotal）の分母をどう定義するかという問題。

選択肢は2つあった：
1. **全評価軸を分母にする** — 未入力は暗黙的に0点
2. **入力済み評価軸のみを分母にする** — 未入力は計算から除外

## Decision
**全評価軸を分母にする（選択肢1）** を採用する。

## Rationale
- 入力済みのみを分母にすると「3軸だけ入れて合致度100%」という誤解が生じ、求人の質を過大評価するリスクがある
- 比較画面で入力量が異なる求人を並べたとき、スコアの意味が揃わなくなる
- 未入力 = 0点という圧力が、評価入力を促す動機になる
- UIで「未入力 N 軸あり」を明示することで、スコアが低い理由をユーザーが把握できる

## Consequences
- 未評価の求人はスコアが低く表示される。これは意図した挙動
- 比較画面では「未入力軸数」をスコアと並べて表示する必要がある
- 評価軸を追加した場合、既存求人の合致度スコアは即座に下がる（分母が増えるため）
