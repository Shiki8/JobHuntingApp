# ADR 0005: 比較画面を評価軸スコア比較から基本情報比較に変更する

## Status
Accepted

## Context
当初の比較画面は「行=評価軸・列=求人」のマトリクスで、各求人に対するスコアを並べて優劣を判断する設計だった。しかし実際の転職判断では「年収・リモート・勤務地といった条件を横断して見比べる」ニーズが主であり、スコアは比較の邪魔になっていた。

## Decision
比較画面を「行=求人・列=基本情報項目」の転置テーブルに変更する。評価軸スコアは表示しない。デスクトップ・モバイルで同一構造を使い、左列（会社名・職種・ステータスバッジ）を固定して項目列を横スクロールで確認する。

## Considered Options

- **評価軸スコアを維持しつつ基本情報列を追加** — テーブルが肥大化し焦点が定まらないため却下。
- **カード形式（グリッドレイアウト）** — 項目を揃えて比較しにくいため却下。

## Consequences

- 評価軸（Criteria）・評価（Score）・合致度スコアは他画面（JobList・JobDetail・ScoreInput）では引き続き利用する。Compare のみ非表示。
- 合致度スコアは将来的に全画面から削除する可能性がある（未決定）。
