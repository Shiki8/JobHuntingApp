# job-list

## Overview

登録済み求人をカード形式で一覧表示し、ステータスタブ・テキスト検索・フィルターで絞り込む機能。求人カードから比較選択を行い、CompareBar 経由で比較画面へ遷移できる。

## Background

転職活動では複数の求人を並行管理するため、一覧で素早く状況を把握・絞り込めることが重要。ステータス別に件数をリアルタイムで確認できることで、選考進捗の全体像を一目で把握できる。

検索は専用のクエリ言語を持たず、企業名・職種・技術スタックをまとめて全文マッチする方式を採用した。これはユーザーが記憶に頼って検索する場合に最もシンプルで直感的なためである。キーボードショートカット（`/` キー）は検索ボックスへのフォーカスを一瞬で行えるようにするためのもので、マウスを使わず操作できる。

比較機能（CompareBar）は求人一覧画面上に浮かび上がる固定バーとして実装することで、別画面に遷移することなく候補を選びながら比較に移れるようにしている。

## User Stories

1. 登録した求人を一覧で眺め、各求人の企業名・職種・ステータス・合致度を素早く確認したい
2. 「面接中」「書類選考中」など特定のステータスのみに絞り込んで、今対応が必要な求人を把握したい
3. 会社名や技術スタックのキーワードで検索し、目当ての求人をすぐに見つけたい
4. 求人媒体（Wantedly、doda など）やリモート可否でフィルタリングしたい
5. 比較したい求人を複数選んで比較画面へ遷移したい
6. キーボードだけで操作を完結させたい（`/` キーで検索フォーカス）

## Behavior

### ステータスタブ

- タブは「すべて」+ `APPLICATION_STATUSES`（7種）の計8タブ
  - `すべて` / `未応募` / `応募済` / `書類選考中` / `面接中` / `最終選考` / `内定` / `見送り`
- 各タブには `CountBadge` で件数を表示する
  - 「すべて」の件数は `jobs.length`（全件数、フィルター非依存）
  - 個別ステータスの件数は `jobs.filter(j => j.status === status).length`（ステータス一致のみカウント、テキスト検索・媒体・リモートフィルターは含まない）
- アクティブなタブは青下線 + 青文字で強調される

### テキスト検索

- 対象フィールド: `companyName`（企業名）、`position`（職種）、`techStack`（技術スタック）
- 大文字・小文字を区別しない部分一致（`toLowerCase().includes(query)`）
- プレースホルダー: `企業名・職種・技術で検索 [/]`
- `/ キー` を押すと検索フォーカスが当たる（ただし入力フォーム・テキストエリアにカーソルがある場合は無効）

### フィルター

| フィルター | 選択肢 | デフォルト |
|---|---|---|
| 媒体 (source) | すべての媒体 / Wantedly / Green / doda / LinkedIn / Findy / 企業サイト / エージェント / その他 | すべての媒体 |
| リモート可否 (remoteType) | すべて / 不可 / 一部リモート / フルリモート | すべて |

- 複数フィルターは AND 条件で適用される
- フィルター状態は `useJobStore` の `filters` に保持され、ページをまたいでも維持される

### 求人カード（JobCard）

各カードに以下を表示する：

- 企業名（1行 truncate）
- ステータスバッジ（`StatusBadge`）
- 職種名（1行 truncate）
- 媒体名（`sourceNote` がある場合は `sourceNote` を優先表示）
- リモート可否・年収レンジ・勤務地のチップ
- 技術スタックタグ（最大4件 + 超過分は `+N` で省略）
- 合致度スコア（`ScoreDots` + パーセンテージ。評価未入力の場合は「評価未入力」と表示）
- 比較チェックボックス（右下。5件満時は非活性化）

カードクリックで `/jobs/:id`（詳細画面）へ遷移する。

### CompareBar

- 比較チェックボックスを1件以上選択した時点で画面下部にスライドアップで表示される（0件時はスライドダウンして非表示）
- 選択中の求人を企業名チップで表示し、チップ内の `×` で個別に選択解除できる（モバイルではチップは非表示、「N件選択中」テキストに集約）
- 「クリア」ボタンで全選択を解除する
- 「N件を比較する」ボタンで `/compare` へ遷移する
- モバイルではボトムナビバーの直上に配置される
- CompareBar 表示中は「求人を追加」FAB（フローティングボタン）が非表示になる（モバイルのみ）

### 空状態（EmptyState）

| 条件 | タイトル | 説明 | アクション |
|---|---|---|---|
| 求人が1件も登録されていない | 求人がまだありません | サイドバーの「求人を追加」から登録してみましょう | 「求人を追加」ボタン（`/jobs/new` へ遷移） |
| 求人は存在するがフィルター・検索条件に0件 | 条件に一致する求人がありません | フィルタや検索条件を変えてみてください | なし |
