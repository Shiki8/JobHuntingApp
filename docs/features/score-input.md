# score-input

## Overview

求人（Job）に対して評価軸（Criteria）ごとに点数・根拠メモ・参照 URL を入力し、一括保存する機能。入力した点数は合致度スコアの計算に使われ、比較画面での求人比較を可能にする。

## Background

評価は「スコア対象軸（weight > 0）」と「参考記録軸（weight = 0）」に分かれる。前者のみが合致度スコアの計算に影響し、後者は定性メモとして残す。

合致度スコアの算出式は以下の通り：

```
合致度スコア = round(Σ(score × weight) / Σ(weight × 5) × 100)
```

分母は入力済み軸ではなく**全評価軸**（weight > 0 のすべての軸）を使う。これにより「3軸だけ入れて合致度100%」という過大評価を防ぎ、複数求人間でスコアの意味が統一される（詳細は [ADR-0001](../adr/0001-weighted-total-denominator.md)）。

評価軸は `/criteria` で事後追加できる。軸を追加すると分母が増えるため、既存求人の合致度スコアは即座に下がる。これは意図した挙動。

## User Stories

1. 求人ごとに評価軸の点数（1〜5点）を入力して合致度スコアを可視化したい
2. 点数と一緒に「なぜその点数か」の根拠メモや参照 URL を残して、後から判断を見直せるようにしたい
3. スコア対象軸と参考記録軸が画面上で分かれており、どちらを入力しているか意識しながら作業したい
4. 進捗バーで「何軸中何軸を入力済みか」を把握しながら入力したい
5. 一度入力した評価を再編集したとき、前回の内容がそのまま残っていてほしい
6. 評価軸が後から追加されたときも、既存の評価データを失わずに新しい軸の入力欄が追加されてほしい

## Behavior

### 評価軸のセクション分け

- **スコア対象（weight > 0）**: 合致度スコアの計算に含まれる。カードのヘッダに「重み N」を表示。未入力時は「未入力」ラベルをアンバー色で表示。
- **参考記録（weight = 0）**: 合致度スコアに影響しない。カードのヘッダに「スコア対象外」バッジを表示。

評価軸は `order` 昇順で表示される。

### ScoreDots のクリックトグル仕様

- 1〜5の5つのドットが横に並ぶ（`src/components/ui/ScoreStars.tsx` の `ScoreDots` コンポーネント）
- 点数未設定の初期状態はすべてグレー（score = 0）
- ドットをクリックするとその点数に設定される
- **すでに設定済みの点数と同じドットをクリックすると 0（未入力）に戻る**（トグル挙動）
- 設定済みのドットは青く塗りつぶされ、未設定はグレーで表示される

### 根拠メモ・参照 URL フィールド

- **根拠メモ**: 複数行テキストエリア（2行）。リサイズ可能。プレースホルダー「根拠・理由を書いておくと比較時に役立ちます」
- **参照 URL**: `type="url"` の単行テキスト入力。任意入力。プレースホルダー「参照URL（任意）」

### 進捗バー

- スコア対象軸（weight > 0）の入力状況のみをカウント
- `enteredCount / totalActive * 100`（`Math.round` 適用）をパーセントで表示
- 「N / M 軸入力済み」と数値も合わせて表示
- 全軸入力完了時（`enteredCount === totalActive && totalActive > 0`）にグリーンの完了メッセージを表示

### 一括保存ボタン

- **ヘッダ**と**フッタ（スクロール末尾）**の2箇所に配置
- クリック時にすべての評価軸の `(score, memo, referenceUrl)` を `useScoreStore.upsertScore` に書き込む
- 保存成功後2秒間、ボタンがグリーン（`bg-green-600`）になりチェックアイコスと「保存しました」テキストを表示し、2秒後に元の「一括保存」表示に戻る

### 再編集時の既存スコア読み込み

- ページ初期化時（`useState` のイニシャライザ）に `useScoreStore.getScore(jobId, criteriaId)` を呼び、既存の `score / memo / referenceUrl` をドラフト状態に読み込む
- 評価軸が後から追加された場合（`useEffect` で検知）、新しい軸のドラフトエントリが追加される。既存軸のドラフトは上書きされない

### バリデーション・エッジケース

| ケース | 挙動 |
|---|---|
| 評価軸が 0 件 | スコア入力エリアの代わりに「評価軸が設定されていません」メッセージと `/criteria` へのリンクを表示 |
| スコア対象軸が 0 件（weight > 0 の軸なし） | 進捗バーは非表示。参考記録セクションのみ表示 |
| `id` が存在しない求人 ID | 「求人が見つかりません」メッセージを表示 |
| 未入力のまま保存 | score = 0 のまま upsertScore が呼ばれる（エラーなし。合致度スコアは 0 点として計算される） |
