# compare

## Overview

比較選択した求人を横断的に見比べるための基本情報テーブル機能。行が求人・列が基本情報項目の転置テーブル構造で、勤務地・年収・リモート可否などの条件を一覧できる。

## Background

当初の比較画面は「行=評価軸・列=求人」のマトリクスで合致度スコアを並べる設計だったが、実際の転職判断では条件（年収・リモート・勤務地など）を横断して見比べるニーズが主となり、スコア行は焦点を分散させていた。

ADR-0005 の決定に従い、比較画面を「行=求人・列=基本情報項目」の転置テーブルに刷新した。評価軸スコア・合致度スコアは Compare からは除外し、JobList・JobDetail・ScoreInput で引き続き利用する形に分離している。

## User Stories

1. 比較選択した求人の勤務地・年収・リモート可否・雇用形態をまとめて見比べて、条件面での優劣を把握したい
2. 横スクロールで多くの比較項目を確認しながら、会社名と応募ステータスを常に左端に固定して文脈を見失わないようにしたい
3. 気になる求人を比較画面から直接除外したり、評価入力画面に遷移したりして、比較→判断のサイクルを素早く回したい
4. スキル系フィールドが長い場合でも、先頭3件と残り件数の省略表示で一覧の見通しをよくしたい
5. 比較対象が2件未満のときは一覧に戻るための案内だけを表示し、中途半端なテーブルを見せないでほしい

## Behavior

### テーブル構造

- **行**：比較選択中の求人（`useCompareStore.selectedIds` の順序）
- **左固定列**：会社名（太字・最大2行）・職種（1行省略）・応募ステータスバッジ
- **スクロール列**：以下の順序で並ぶ

| 列 | フィールド | 備考 |
|---|---|---|
| 勤務地 | `location` | 未設定時は `—` |
| 年収 | `salaryMin` / `salaryMax` | `最小〜最大万` / 片方のみの場合は `最小万〜` or `〜最大万` |
| 始業時間 | `workStartTime` | 未設定時は `—` |
| リモート可否 | `remoteType` | enum 値をそのまま表示 |
| 年間賞与 | `annualBonus` | 未設定時は `—` |
| 年末年始休暇 | `yearEndHolidays` | 日数（数値）。未設定時は `—` |
| 住宅補助 | `housingAllowance` | あり：`✓` / なし：`—` |
| 雇用形態 | `employmentType` | enum 値をそのまま表示 |
| 必須スキル | `requiredSkills` | 先頭3件をタグ表示、残りを `+N` で省略 |
| 技術スタック | `techStack` | 先頭3件をタグ表示、残りを `+N` で省略 |
| 媒体 | `source` / `sourceNote` | source が `'その他'` かつ sourceNote がある場合は `その他: {sourceNote}` |
| 気になる点 | `notes` | 最大4行で折り返し（`line-clamp-4`）、最小幅 200px |

### スキル系フィールドの省略ルール

`requiredSkills` と `techStack` は配列の先頭3件をグレーの小タグ（`bg-gray-100`）で表示する。4件目以降がある場合は `+N`（小字・グレー）で件数のみ表示する。空配列の場合は `—` を表示する。

### TOPバッジ（合致度スコア最大列の青ハイライト）

現バージョンの実装では Compare 画面に合致度スコアは表示されない（ADR-0005 に基づきスコア行を除去済み）。TOPバッジが必要な場合は将来の拡張として検討する。

### 固定左カラムの実装

`sticky left-0 z-10`（tbody）/ `z-20`（thead）で CSS sticky を使用。偶数行は `bg-white`・奇数行は `bg-gray-50` のストライプを左固定列にも個別に適用することで、スクロール時の透過を防いでいる。

### 2件未満の空状態

比較対象が2件未満の場合は `EmptyState` コンポーネントを表示し、テーブルは描画しない。ページ自体はリダイレクトせず `/compare` のままとする。「求人一覧に戻る」ボタン（`navigate('/')`）のみ提供する。

### 列ヘッダからの操作

| 操作 | 動作 |
|---|---|
| 列ヘッダの「評価を編集」リンク | `/jobs/:id/score` へ遷移 |
| 列ヘッダの「×」ボタン | `useCompareStore` から該当 ID を除外し、2件未満になれば空状態に切り替わる |

> **注**: 現バージョンの `Compare.tsx` では列ヘッダに「評価を編集」と「×」ボタンは未実装。行は求人ごとに左固定列で識別し、ヘッダには項目名のみ表示する。上記は仕様書としての記載であり、今後の実装対象。

### 「選択をクリア」ボタン

比較対象が2件以上のときのみヘッダ右上に表示。クリックで `useCompareStore.clear()` を呼び出し、全選択を解除して空状態に移行する。
