# job-browsing-flow

## Overview

ユーザーが求人一覧（`/`）を起点に求人を絞り込み、詳細確認・比較候補への追加までを行うフロー。テキスト検索・ステータスタブ・媒体/リモートフィルターを組み合わせて目当ての求人に素早くたどり着くことができる。

## Actors

- **ユーザー**: 登録済みの求人を閲覧・検索・フィルタリングし、詳細確認や比較を行う

## Flow

### 求人一覧を開く

1. アプリを開くと `/`（求人一覧）が表示される
2. 登録済みの求人がカードグリッドに並ぶ。各カードには企業名・職種・ステータス・技術スタック・合致度が表示される
3. ページヘッダーの `CountBadge` に総件数が表示される

### ステータスタブで絞り込む

4. タブバーに「すべて」＋7つのステータス（未応募 / 応募済 / 書類選考中 / 面接中 / 最終選考 / 内定 / 見送り）が並ぶ
5. 各タブの `CountBadge` でそのステータスの件数を確認できる
6. タブをクリックすると、選択したステータスの求人のみ表示される

### テキスト検索で絞り込む

7. 検索ボックスにキーワードを入力すると、企業名・職種・技術スタックが部分一致で絞り込まれる
8. `/ キー` を押すと検索ボックスにフォーカスが移る（入力フォーム・テキストエリアにカーソルがある時は無効）

### フィルターで絞り込む

9. 媒体ドロップダウンから求人媒体（Wantedly / Green / doda / LinkedIn / Findy / 企業サイト / エージェント / その他）を選択できる
10. リモートドロップダウンからリモート可否（不可 / 一部リモート / フルリモート）を選択できる
11. ステータスタブ・テキスト検索・媒体・リモートの各条件は AND で組み合わさる

### 求人詳細を確認する

12. 求人カードをクリックすると `/jobs/:id`（詳細画面）へ遷移する

### 比較候補に追加する

13. 求人カード右下の比較チェックボックスをクリックすると、その求人が比較候補に追加される
14. 1件以上選択された時点で、画面下部に CompareBar がスライドアップで表示される（モバイルではボトムナビバーの上に表示され、「求人を追加」FAB は非表示になる）
15. CompareBar には選択中の求人が企業名チップで並ぶ。チップ内の `×` で個別に解除できる（モバイルでは「N件選択中」テキストに集約）
16. 「N件を比較する」ボタンをクリックすると `/compare`（比較画面）へ遷移する
17. 「クリア」ボタンで全選択を解除する

## Edge Cases

- **求人が1件も登録されていない**: 空状態として「求人がまだありません」と「求人を追加」ボタンが表示される。タブバーはすべて `0` 件表示になる
- **フィルター適用後に0件になった**: 「条件に一致する求人がありません」と説明文が表示される。アクションボタンは表示されない。フィルターを変更することで一覧に戻れる
- **比較対象が5件に達した場合**: `useCompareStore.isFull()` が `true` になり、未選択の求人カードのチェックボックスが非活性（opacity-40 / cursor-not-allowed）になる。既選択の求人は引き続き解除できる
- **`/` キーを入力欄にフォーカスがある状態で押した場合**: 検索ボックスへのフォーカス移動は行われず、通常の `/` 文字入力として処理される
- **媒体が「その他」かつ `sourceNote` がある場合**: カード上の媒体表示は `source`（その他）ではなく `sourceNote` の値が優先して表示される
- **技術スタックが5件以上ある場合**: カードには先頭4件のみタグ表示され、残りは `+N` でまとめて表示される。詳細画面ではすべて確認できる
