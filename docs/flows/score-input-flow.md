# score-input-flow

## Overview

ユーザーが求人詳細画面から評価入力画面（`/jobs/:id/score`）に遷移し、評価軸ごとに点数・根拠メモ・参照 URL を入力して一括保存するフロー。保存された点数は合致度スコアの算出と比較画面での比較に使われる。

## Actors

- **ユーザー**: 求人詳細を確認し、評価軸への採点・メモ記入・保存を行う

## Flow

1. ユーザーが求人一覧（`/`）または求人詳細（`/jobs/:id`）から「評価を入力」ボタンをクリックする
2. 評価入力画面（`/jobs/:id/score`）に遷移する
3. ページ初期化時に `useScoreStore.getScore(jobId, criteriaId)` が呼ばれ、既存の評価データがドラフトに読み込まれる（再編集の場合）
4. ヘッダに求人名・役職・ステータスバッジが表示される
5. 進捗バー（「スコア対象軸の進捗：N / M 軸入力済み」）が表示される
6. **スコア対象（weight > 0）** セクションの各評価軸カードに対して：
   a. ScoreDots（1〜5のドット）をクリックして点数を設定する（同じドットを再クリックで 0 にリセット）
   b. 根拠メモテキストエリアに評価の根拠・理由を記入する（任意）
   c. 参照 URL フィールドに根拠となる URL を入力する（任意）
7. **参考記録（weight = 0）** セクションがある場合、同様に入力できる（合致度スコアには影響しない）
8. 入力のたびに進捗バーがリアルタイムで更新される。全軸入力完了時はグリーンの完了メッセージが表示される
9. ヘッダまたはフッタの「一括保存」ボタンをクリックする
10. すべての評価軸の `(score, memo, referenceUrl)` が `useScoreStore.upsertScore` に書き込まれる
11. 保存成功後2秒間、ボタンがグリーン表示になり「保存しました」と表示される
12. ユーザーは「←」ボタンで求人詳細（`/jobs/:id`）に戻る

## Edge Cases

| ケース | 挙動 |
|---|---|
| 対象求人が存在しない（不正な ID） | 「求人が見つかりません」メッセージを表示。入力エリアは表示されない |
| 評価軸が 0 件 | 「評価軸が設定されていません」メッセージと `/criteria` へのリンクを表示。保存ボタンは表示されない |
| スコア対象軸が 0 件（全軸 weight = 0） | 進捗バーのパーセント計算対象なし。参考記録セクションのみ表示 |
| 点数を入力せずに保存 | score = 0 のまま upsertScore が呼ばれる。エラーにはならず、合致度スコアは 0 点として計算される（ADR-0001 の意図通り） |
| 評価軸が後から追加された場合 | `useEffect` が新しい軸を検知し、ドラフトにエントリを追加する。既存軸の入力内容は保持される |
| 保存後にすぐ再保存 | 2秒のグリーン表示タイマーがリセットされず継続する。再度ボタンをクリックすれば上書き保存される |
| ページ離脱（未保存のまま「←」ボタン） | 未保存のドラフトは破棄され、求人詳細画面に戻る。保存確認ダイアログは表示されない |
